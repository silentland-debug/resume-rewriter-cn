# Gongda Mechanical Resume Changelog

## 2026-09-20

### 潜在线索扫描

把原来的“补证据”升级为两步：

1. 先从竞赛、课程设计、论文/专利、简略项目和一句带过的实习内容中扫描潜在线索；
2. 再追问真正影响岗位判断的缺口。

新增规则：

- 不直接问学生“有没有和 JD 匹配的经历”，而由 GPT 先从原材料发现线索，再问具体事实。
- 竞赛名称只能作为线索，不能直接证明建模、工程图、加工、装配等技术工作。
- 若确认竞赛背后存在真实且与 JD 直接相关的技术贡献，可把竞赛从荣誉奖项升级为项目经历。
- 删除或压缩竞赛、课程、论文等材料前，先检查是否会误删潜在岗位证据。

### 学生自助模式

保持学生本人直接使用的交互逻辑：一次只追问一个最关键问题，学生负责回忆事实，GPT 负责判断岗位匹配和材料取舍。
