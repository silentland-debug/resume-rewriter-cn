# JD定制闭环：拆 → 对 → 补 → 选 → 改 → 审 → 定

## 1. 拆：拆JD

不要先改简历。先用学生能听懂的语言回答：
- 入职后主要做什么？
- 硬门槛是什么？
- 核心专业能力是什么？
- 加分项是什么？
- 企业最终关心什么结果：质量、效率、精度、成本、交付、可靠性等？
- 这个岗位最核心的任务链是什么？

机械设计/结构类可优先按：
`需求 → 方案 → 建模 → 出图 → 加工/采购 → 装配 → 调试 → 验证/闭环`

不同岗位可使用不同任务链，不机械套用。

目标：让学生先说清“这个岗位本质上在招什么样的人”。

## 2. 对：证据匹配

逐项把JD要求与简历材料对应，区分：
- 直接证据
- 可迁移证据
- 暂无证据
- 信息冲突/需要确认

必须指出证据来自哪段工作、实习、科研、项目或课程设计。不能因为JD需要就推测学生具备。

建议内部形成证据台账：

| JD要求 | 证据来源 | 证据类型 | 当前强度 | 处理 |
| --- | --- | --- | --- | --- |
| 一项真实要求 | 某段经历 | 直接/可迁移/暂无/冲突 | 强/中/弱 | 展开/保留/追问/删除 |

## 3. 补：先挖潜在线索，再追关键缺口

默认一次只问1个最关键问题。只有互不依赖且学生回答成本低时，才同时问2—3个。

### 3.1 先扫描“没展开的材料”

第一轮证据匹配后，不要只盯着已经写成项目经历的内容。继续扫描：
- 技术竞赛与奖项名称；
- 课程设计、毕业设计和大作业；
- 论文、专利、科研课题；
- 只有项目名称、没有动作与结果的简略项目；
- 实习/工作中一句带过、但可能包含设计、加工、装调、测试或异常处理的内容。

如果某项名称与JD方向明显相关，先把它当作“潜在线索”，而不是直接当作证据，也不要立即删除。优先挑与JD最相关的1项追问。

不要问学生抽象问题：`你的竞赛里有没有和JD匹配的？`

学生未必知道如何判断岗位匹配。应由GPT先根据JD发现线索，再问事实，例如：

`你简历里写了“全国三维数字化创新设计大赛省级一等奖”。这个比赛当时具体做的是什么作品或项目？你本人主要负责哪一部分？`

学生只负责回忆事实；GPT负责判断这些事实是否能对标JD。

### 3.2 再追真正缺失的证据

确认潜在线索后，再围绕最影响岗位判断的缺口继续追问：
- 你本人具体做了什么？
- 用了什么工具/方法？
- 遇到什么具体问题？
- 最后交付了什么？
- 项目最终做到什么状态？完成了哪些测试？
- 有无真实指标、工程图、BOM、样机、程序、报告、论文/专利对应成果？

不要一上来就追数字。先还原工作和工程链，再核实可验证数字。

### 3.3 竞赛材料升级规则

如果追问后发现竞赛背后存在与JD直接相关的真实技术工作：
- 不再只把它放在“荣誉奖项”；
- 判断是否升级为“项目经历”；
- 按 `项目对象 → 本人任务 → 工具/方法 → 工程交付/结果` 表达；
- 奖项可作为该项目的结果之一。

如果学生只是参赛、本人技术贡献不清，或内容与岗位弱相关，则仍按普通荣誉压缩或删除。

竞赛名称、奖项级别和行业常识都不能替代真实项目事实。行业常识只用于发问，不用于补事实。

## 4. 选：决定材料取舍

不要把“看起来厉害”当保留理由。按岗位价值决定：
- 最值得保留的3—5项材料
- 哪些展开
- 哪些压缩
- 哪些删除
- 页面顺序

向学生解释关键取舍时，用招聘逻辑，例如：
`这段不是不好，而是这个JD更需要结构设计证据，一页版面有限，所以先压缩。`

## 5. 改：企业语言转译

只使用已确认事实。优先结构：

**问题/场景 → 本人动作 → 方法/工具 → 工程交付/结果**

科研项目特别强调：设计对象、结构方案、建模/仿真、工程图/BOM（仅有证据时）、加工制造、供应商对接、装配、调试、测试、最终结果。

不得新增数字、客户、量产、成本节省、效率提升、职责范围或团队成果归因。

## 6. 审：招聘筛选视角锐评

把改稿当成新材料审查：
- 是否一眼看懂目标岗位？
- 是否仍有低相关内容？
- 是否有说太满、AI包装、职责扩大？
- 是否新增了原材料没有的事实？
- 最关键岗位证据是否被埋住？
- 是否还有重复、废话和过度解释？
- 每个核心结论能否追溯到真实证据？

不要为挑错而挑错，只列最值得改的问题。

## 7. 定：最终修订

只修审查发现的真实问题，不推倒重写。保留有效内容，输出当前JD版本。

最终版完成后，告诉学生：
- 当前版本最强的2—3项岗位证据；
- 仍然缺失的1—3项关键证据；
- 这些缺口是“简历没写”还是“本人暂时没有”，两者不要混淆。

## 学生可直接使用的简版指令

- 拆JD：`先不要改简历，拆解这个JD的实际工作、硬门槛、核心能力和企业关心的结果。`
- 对证据：`对照JD分析我的经历，只找直接证据、可迁移证据、暂无证据，不要补事实。`
- 补证据：`先扫一遍竞赛、课程设计、论文和简略项目，看有没有没展开但和JD相关的证据；再一次只问我一个最关键的问题。`
- 改写：`只用已确认事实，按问题/场景—本人动作—方法/工具—交付/结果改写。`
- 审查：`不要继续润色，按招聘筛选视角检查无关内容、夸大、新增事实和关键证据是否突出。`
- 防编造：`逐条检查有没有原材料不支持的新数字、新职责、新成果或新工具。`
