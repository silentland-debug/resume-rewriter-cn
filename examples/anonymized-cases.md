# Anonymized Cases

以下案例均为脱敏或虚构片段，用于展示 `resume-rewriter-cn` 的核心能力：从 HR 视角判断简历内容，并从候选人原始经历中深度挖掘被忽略的技能、流程、工具和交付物。

## Case 1: HR / 招聘方向

### 原始表达

```text
人事助理：协助发布招聘信息，对候选人进行初步匹配评估，为招聘团队提供人才资源支持。
```

### HR 视角分析

HR 看到这句话，会继续想知道：

- 候选人是否熟悉招聘流程？
- 做过哪些具体环节：发布、筛选、沟通、邀约、面试安排、台账？
- 有没有使用 Excel 或招聘系统做信息整理？
- 是否能支持招聘效率和流程推进？

### 隐藏价值挖掘

从“招聘信息发布、候选人初步匹配、招聘团队支持”中，可以合理挖掘：

- 招聘需求理解
- 招聘信息发布
- 简历/候选人初筛
- 候选人沟通
- 面试邀约与进度跟进
- 招聘台账维护

### 优化表达

```text
协助发布招聘信息，按照岗位要求整理候选人资料并完成初步匹配评估，跟进候选人沟通、面试邀约和招聘进度维护，为招聘团队推进选筛流程提供信息支持。
```

### 注意边界

没有原始数据时，不添加“筛选 300 份简历、邀约 80 人、到面率提升”等结果。

## Case 2: 机械助理 / 质量检验

### 原始表达

```text
质量检验员：负责检查外观、边缘、孔位、配合完整性，区分冲压、CNC 加工产生的毛刺、碰伤、变形缺陷。
```

### HR 视角分析

机械或制造类岗位的 HR/用人部门会关注：

- 是否接触过真实产线或精密零件？
- 是否知道检验对象和缺陷类型？
- 是否理解加工工艺和质量标准？
- 是否具备记录、反馈和现场品控意识？

### 隐藏价值挖掘

这段经历不只是“检查外观”，还可以呈现：

- 精密零件检验对象
- 外观、孔位、配合完整性检查
- 冲压/CNC 工艺缺陷识别
- 检验标准意识
- 质量记录和现场品控经验

### 优化表达

```text
依据检验标准检查精密零件外观、边缘、孔位和配合完整性，识别冲压、CNC 加工过程中产生的毛刺、碰伤、变形等缺陷，整理质量记录，积累精密五金件现场品控经验。
```

### 注意边界

如果原文没有写检测数量、良率或返工情况，不编造生产数据。

## Case 3: 机械助理 / SolidWorks 项目

### 原始表达

```text
运用 SolidWorks 完成齿轮泵零件建模与装配，利用钣金模块设计风扇支架。
```

### HR 视角分析

用人部门不只想知道“会 SolidWorks”，还想知道：

- 是单个零件建模，还是装配建模？
- 有没有检查干涉、考虑可加工和可装配？
- 有没有输出工程图、爆炸图、BOM 等交付物？
- 是否具备基础工程表达能力？

### 隐藏价值挖掘

可以挖掘出的岗位价值：

- 零件建模
- 装配关系理解
- 干涉检查
- 钣金折弯和孔位布局
- 工程图/爆炸图/BOM 输出
- 可加工、可装配意识

### 优化表达

```text
使用 SolidWorks 完成齿轮泵零件建模与装配，通过干涉检查优化结构合理性，并输出工程图、爆炸图及 BOM 清单；运用钣金模块完成风扇支架设计，优化折弯与孔位布局，强化结构可加工和可装配意识。
```

## Case 4: 护理应届生 / 志愿服务

### 原始表达

```text
积极参加学校护理志愿服务团队，定期前往社区、养老院开展健康义诊和护理知识普及活动。
```

### HR 视角分析

护理岗位不需要泛泛的“志愿服务精神”，更需要看到：

- 是否接触真实服务对象？
- 是否做过健康宣教、基础监测或患者沟通？
- 是否能体现耐心、规范、服务意识和护理岗位相关性？

### 隐藏价值挖掘

可提炼为：

- 社区/养老院服务对象
- 健康义诊
- 血压监测或基础健康咨询
- 护理知识宣教
- 老年群体沟通
- 护理服务意识

### 优化表达

```text
参与社区及养老院健康服务，协助开展血压监测、健康咨询和基础护理知识宣教，面向老年群体进行健康沟通，锻炼患者沟通、耐心倾听和护理服务意识。
```

### 内容重组

如果同一份简历里还有礼仪队、训练营等经历，不应和护理志愿服务混写。护理志愿服务可以单独展开，礼仪队只保留职业仪态、服务规范和现场秩序等可迁移价值。

## Case 5: 校园组织经历 / 弱相关转译

### 原始表达

```text
担任学生会干部，组织多项校园活动，提升了组织能力和团队协作能力。
```

### HR 视角分析

这句话的问题是：结果很空，过程不清。HR 看不到候选人具体做了什么。

应该追问：

- 负责策划还是执行？
- 是否做过任务分工、人员协调、宣传物料、现场问题处理？
- 是否能迁移到岗位所需的沟通、执行和文档能力？

### 隐藏价值挖掘

可挖掘为：

- 活动策划
- 任务分工
- 跨部门沟通
- 现场执行
- 问题处理
- 资料整理和复盘

### 优化表达

```text
负责校园活动的任务分工、现场协调和资料整理，跟进活动执行节点，协助处理现场问题，沉淀活动组织、跨部门沟通和执行复盘经验。
```

### 取舍判断

如果目标岗位是 HR、运营、教育、行政，这段可保留并转译。  
如果目标岗位是机械、研发、护理等强专业岗位，且篇幅紧张，这段应压缩或删除。

## Case 6: 服役经历 / 差异化背书

### 原始表达

```text
中国人民解放军某部队服役，担任瞄准手，参加演习任务。
```

### HR 视角分析

这类经历的价值不是简单写“抗压能力强”，而是要让企业看到可迁移能力：

- 纪律意识
- 任务执行
- 流程服从
- 团队协同
- 复杂环境响应
- 现场执行稳定性

### 优化表达

```text
曾在中国人民解放军某部服役，担任瞄准手并参与演习任务，在高纪律、高标准任务环境中完成岗位执行，形成流程服从、团队协同和复杂环境响应能力。
```

### 取舍判断

如果目标岗位重视纪律、执行、服务、管理、国央企或教育行业稳定性，这段应前置到任职优势。  
如果目标岗位高度技术化，则保留事实并压缩表达，避免喧宾夺主。
